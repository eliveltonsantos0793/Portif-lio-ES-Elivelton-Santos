# Portfólio — Elivelton Santos

Portfólio pessoal desenvolvido com **HTML5, CSS3 e JavaScript puro**, com foco em apresentação profissional, responsividade e facilidade de manutenção.

## Funcionalidades

- Layout responsivo para celulares, tablets e computadores.
- Menu de navegação adaptado para dispositivos móveis.
- Seções de início, sobre mim, serviços, projetos, processo de trabalho e contato.
- Links para GitHub, LinkedIn, WhatsApp e e-mail.
- Formulário de contato usando o serviço FormSubmit.
- Animações suaves ao rolar a página.
- Destaque da seção atual no menu.
- Metadados básicos para SEO.
- Respeito à preferência do sistema por redução de animações.
- Código separado em arquivos HTML, CSS e JavaScript.

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** identidade visual, layout e responsividade.
- **JavaScript:** menu mobile, navegação ativa, animações e ano automático no rodapé.

## Como executar localmente

1. Baixe e extraia os arquivos do projeto.
2. Abra a pasta no Visual Studio Code ou outro editor.
3. Abra o arquivo `index.html` no navegador.
4. Para uma experiência de desenvolvimento mais prática, use a extensão **Live Server** do Visual Studio Code e selecione **Open with Live Server**.

O site utiliza HTML, CSS e JavaScript estáticos; não é necessário instalar dependências para visualizá-lo localmente.

## Personalização antes de publicar

Revise e confirme as informações de contato no arquivo `index.html`, incluindo:

- Endereço de e-mail.
- Número e link do WhatsApp.
- Perfil do LinkedIn.
- Perfil e links dos projetos no GitHub.

Também é recomendado substituir imagens ilustrativas por capturas de tela dos projetos reais e conferir se todos os links estão corretos.

## Formulário de contato

O formulário utiliza o serviço externo **FormSubmit**. Na primeira utilização, o serviço pode solicitar a confirmação do endereço de e-mail configurado no formulário.

Antes de divulgar o portfólio, envie uma mensagem de teste e confirme se ela chega corretamente. Consulte a documentação em [formsubmit.co](https://formsubmit.co/).

## Publicação com GitHub Pages

1. Envie os arquivos do projeto para um repositório no GitHub.
2. Abra o repositório e acesse **Settings**.
3. No menu lateral, selecione **Pages**.
4. Em **Build and deployment**, escolha a publicação a partir de uma branch.
5. Selecione a branch principal (por exemplo, `main`) e a pasta `/ (root)`, caso `index.html` esteja na raiz.
6. Salve e aguarde o GitHub Pages publicar o site.

As opções podem variar conforme a configuração do repositório. Consulte a documentação oficial: [GitHub Pages](https://docs.github.com/pages).

## Acessibilidade e manutenção

- Mantenha textos alternativos (`alt`) descritivos nas imagens informativas.
- Verifique o contraste de cores e a navegação por teclado após alterações.
- Teste o layout em diferentes larguras de tela.
- Confira o console do navegador se algum recurso deixar de funcionar.
